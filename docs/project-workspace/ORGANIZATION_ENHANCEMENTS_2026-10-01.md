# 组织架构增强（2026-10-01）

部门配置保存后，所选小组的组长默认向部长汇报。小组配置可以直接选择所属部门，组员默认向组长汇报，组长默认向已配置的部长汇报。后台将组织归属和汇报关系放在同一事务中保存，拒绝跨公司对象、汇报循环和互相冲突的上级。

部门和小组卡片直接展示成员正在进行的任务（状态为 in_progress），包括执行人和项目名称。部门范围包含部长和所属小组的成员。点击“进入会话”打开对应任务的会话页；未分配给这些成员的任务不混入卡片。组织概览一次读取任务汇总，避免每个小组分别查询。

智能体采用“组员 → 组长 → 部长 → 总管”头衔选项，仍支持原有自定义职位。智能体页面可以按头衔筛选，并与状态及项目范围组合使用。头衔是展示和筛选字段，不会通过修改头衔自行提升执行权限；权限仍由原有模板与授权控制。

项目的“配置”页面可以勾选关联的部门和小组，并一键带入所选部门的小组。关联是独立的多对多关系，不改变小组的主要负责项目。所选小组成员加入当前项目团队；取消组织关联后，项目成员仍可在“团队”中单独管理。保存空选择会清空关联，不会再次自动带入小组。

模板页面支持同时编辑默认 Skills 和 Markdown Instructions。设置按公司保存，使用模板新建智能体时默认生成其托管的 AGENTS.md。已有智能体不跟随模板后续修改。恢复内置默认需要点击保存后才生效。

数据库新增模板默认指令字段（0282），组织插件新增项目归属记录（005）。原有仅更新 Skills 的模板接口保留，且不会覆盖已有默认 Instructions。插件的原生组织写入由后台的限定组织操作处理，插件 SQL 的核心表只读边界保留。
